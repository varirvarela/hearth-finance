Cascading Tiles — Design Notes

  • Level 1 (Group tiles) — one tile per spending group (Casa, Kids, Salidas, Auto, Shopping, Travel). Each shows total spent/budget, mini progress bar, and category count. Click → Level 2.
  • Level 2 (Category tiles) — category grid inside the selected group. Same tile design as current. Each tile shows icon, name, spent/budget, bar, percentage. Click → Level 3.
  • Level 3 (Category detail) — full detail panel: large progress bar with pace tick, 4 stat cards, 6-month sparkline chart, recent transactions list.
  • Breadcrumb navigation at the top lets users jump back to any level without using the back button: "All groups › Casa › Utilities".
  • Summary cards and overall bar stay sticky at the top across all 3 levels — total spending context is never lost.
  • Color encoding is consistent: green = under pace, amber = approaching limit, red = over budget. Status dot on each tile gives a second visual signal.
  • Pace tick on all progress bars marks today's elapsed month position so over/under pace is instantly readable.
  • Projection in Level 3 shows month-end estimate based on current pace — early warning before actually going over.
