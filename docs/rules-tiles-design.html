Rules Tiles — Design Notes (Level 1)

  • One tile per target category — groups all rules that categorize a transaction into that category.
  • Field badges (merchant, desc, account, amount, source) immediately show what attributes are being matched — color-coded by field type for quick scanning.
  • Active/paused badge at top-right of each tile gives instant health status without opening the category.
  • Tiles ordered by rule count (most rules first) — your most-configured categories surface at the top.
  • Clicking a tile → Level 2 shows rules for that category grouped by which field they match on.

Rules Tiles — Design Notes (Level 2)

  • Rules grouped by match field (Merchant Name, Description, Account Name, Amount, Source) — each group has a colored header matching the field badge color from Level 1.
  • Rule cards show: field pill → operator → pattern (code-styled), priority badge, edit, delete, and toggle (on/off).
  • Paused rules appear dimmed (55% opacity) — still visible and editable, but won't be applied to new transactions.
  • Priority number (p10, p20…) shows execution order — lower = higher priority. Rules within the same field group are sorted by priority.
  • "+ Add rule" button in the header pre-fills the rule editor's category field, so adding a rule for the category you're viewing is one click.
  • Toggle per rule enables instant pause/resume without deleting — useful for seasonal merchants.
  • Back to Level 1 via breadcrumb: "All categories › Dining & Bars".
